# アプリアイコン刷新 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ランチャーアイコンを「白いマップピン × コーヒー豆」に刷新し、アプリ内テーマ色と揃え、Android 13 以降のテーマアイコンに対応する。

**Architecture:** Adaptive Icon の前景 drawable を白いパスのみで再構築する。豆は `fillType="evenOdd"` による透明な穴として表現し、割れ目はその穴を跨ぐ白いストロークとして重ねる。前景に背景色を塗らないことで、同一ファイルを `<monochrome>` にそのまま流用できる。

**Tech Stack:** Android `VectorDrawable` (XML)、Gradle (`./gradlew`)、Android Emulator (`android-37.0` システムイメージ)、`adb`

**Spec:** [docs/superpowers/specs/2026-08-21-app-icon-design.md](../specs/2026-08-21-app-icon-design.md)

## Global Constraints

- 配色は背景 `#006241`、前景 `#FFFFFF` のみ。公式グリーン `#00704A`、サイレン（人魚）ロゴ、"Starbucks" ワードマークは一切使用しない。
- 図形はすべて 108dp キャンバス（`viewportWidth=108` / `viewportHeight=108`）上で定義し、セーフゾーン（中央 直径 66dp、y = 21〜87）内に収める。
- 豆は楕円 rx = 11.5 / ry = 16.5、中心 (54, 46)、傾き -45°。割れ目の太さは 4.0、キャップは `round`。
- 前景 drawable には**背景色を塗らない**。豆は必ず透明な穴にする。
- 公開リポジトリのため、コミットメッセージ・PR・スクリーンショットに非公開情報を含めない。
- コミットメッセージは Conventional Commits 形式。`Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` を付与する。`git config commit.gpgsign` は `false` のため署名は不要。
- 単体テストは追加しない。本変更はリソースのみで振る舞いを持たず、XML の内容を文字列照合するテストは AGENTS.md が禁じる tautological なテストに該当する。検証は lint・ビルド・実機（エミュレータ）表示で行う。
- ブランチは `feat/app-icon`（作成済み）。

## 環境メモ

- Android SDK: `/home/spica/Android/Sdk`（`local.properties` の `sdk.dir`）
- `adb` / `emulator` は PATH に無いため、`$ANDROID_HOME/platform-tools` と `$ANDROID_HOME/emulator` を PATH に足して使う。
- `avdmanager` は mise 管理下にあるがグローバル版が未設定のため、`mise x android-sdk@22.0 -- avdmanager ...` の形で呼ぶ。グローバル設定は変更しない。
- 利用可能なシステムイメージは `system-images;android-37.0;google_apis_ps16k;x86_64` のみ。
- AVD は未作成のため、Task 1 で作成する。

### Task 2: アイコンリソースを差し替える

**Files:**
- Modify: `app/src/main/res/drawable/ic_launcher_foreground.xml`
- Modify: `app/src/main/res/drawable/ic_launcher_background.xml`
- Modify: `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
- Modify: `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml`
- Delete: `app/src/main/res/drawable/ic_launcher.xml`
- Create: `docs/icon/after_launcher.png`

**Interfaces:**
- Consumes: Task 1 で作成した AVD `onemorecoffee-icon`
- Produces: `@drawable/ic_launcher_foreground`（前景かつ `<monochrome>` として両用される白パスのみの drawable）

- [ ] **Step 1: 前景 drawable を差し替える**

`app/src/main/res/drawable/ic_launcher_foreground.xml` の内容を以下で全面的に置き換える。

```xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="108dp"
    android:height="108dp"
    android:viewportWidth="108"
    android:viewportHeight="108">
    <path
        android:fillColor="#FFFFFF"
        android:fillType="evenOdd"
        android:pathData="M54,22 C40.2,22 29,33.2 29,47 C29,64.5 54,86 54,86 C54,86 79,64.5 79,47 C79,33.2 67.8,22 54,22 Z M42.333,34.333 a11.5,16.5 -45 1,0 23.334,23.334 a11.5,16.5 -45 1,0 -23.334,-23.334 Z" />
    <group
        android:pivotX="54"
        android:pivotY="46"
        android:rotation="-45">
        <path
            android:pathData="M54,30.5 C47.5,37 60.5,55 54,61.5"
            android:strokeColor="#FFFFFF"
            android:strokeLineCap="round"
            android:strokeWidth="4" />
    </group>
</vector>
```

座標の根拠: 豆の弧の端点 (42.333, 34.333) と (65.667, 57.667) は、中心 (54, 46) から (0, ±16.5) を -45° 回転した点である。2 本目の弧は相対指定 `-23.334,-23.334` で始点に戻る。

- [ ] **Step 2: 背景色を変更する**

`app/src/main/res/drawable/ic_launcher_background.xml` の内容を以下で置き換える。

```xml
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <solid android:color="#006241" />
</shape>
```

- [ ] **Step 3: `<monochrome>` を 2 ファイルに追加する**

`app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` と `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml` の両方を、以下の内容で置き換える（2 ファイルとも同一内容）。

```xml
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher_foreground" />
    <monochrome android:drawable="@drawable/ic_launcher_foreground" />
</adaptive-icon>
```

- [ ] **Step 4: 未参照のレガシーアイコンを削除する**

```bash
git rm app/src/main/res/drawable/ic_launcher.xml
```

削除の根拠（コミット前に再確認すること）:

```bash
grep -rn "ic_launcher" --include="*.xml" --include="*.kt" --include="*.kts" . | grep -v "/build/"
```

期待: 出力に `@drawable/ic_launcher`（末尾が `_foreground` / `_background` でないもの）への参照が 1 件も含まれない。`AndroidManifest.xml` は `@mipmap/ic_launcher` を参照しており、これは `mipmap-anydpi-v26/ic_launcher.xml` に解決される。

- [ ] **Step 5: lint を通す**

```bash
./gradlew :app:lintDebug
```

期待: `BUILD SUCCESSFUL`。指摘が出た場合、`lint.xml` の設定変更や `tools:ignore` で回避せず、内容をユーザーに報告して対応方針を確認する。

- [ ] **Step 6: エミュレータにインストールする**

エミュレータが停止している場合は Task 1 の Step 2〜3 で再起動してから実行する。

```bash
./gradlew :app:installDebug
```

期待: `BUILD SUCCESSFUL`。

- [ ] **Step 7: 変更後のランチャー表示を撮る**

```bash
export ANDROID_HOME=/home/spica/Android/Sdk
ADB="$ANDROID_HOME/platform-tools/adb"
"$ADB" shell input keyevent KEYCODE_HOME
"$ADB" shell input swipe 540 1800 540 600
sleep 2
"$ADB" exec-out screencap -p > docs/icon/after_launcher.png
```

- [ ] **Step 8: 図形を目視で検証する**

`docs/icon/after_launcher.png` を開き、次をすべて満たすことを確認する。満たさない場合は Step 1 の `pathData` を修正して Step 5 から再実行する。

1. 背景がグリーンで、白いマップピンが見える。
2. ピンの中に豆の形の**穴**が空いており、穴の中はグリーン（背景色）である。塗り潰された白い楕円になっていたら `fillType="evenOdd"` か弧の指定が誤っている。
3. 豆が左上から右下へ -45° に傾いている。傾きが逆向きなら弧の `x-axis-rotation` の符号が誤っている。
4. 豆の中に白い割れ目が S 字に走っている。
5. ピンの先端がマスクで切れていない。

### Task 3: テーマアイコンと小サイズ表示を検証する

前景を白パスのみで構成した設計判断が実際に効いているかは、テーマアイコンを有効にしないと確認できない。ここが崩れていると設計の前提が誤っていたことになるため、独立したタスクとして検証する。

**Files:**
- Create: `docs/icon/themed_icon.png`
- Create: `docs/icon/small_size.png`

**Interfaces:**
- Consumes: Task 2 でインストールした新アイコン入りの APK

- [ ] **Step 1: テーマアイコンを有効にする**

エミュレータ上で 設定 → 壁紙とスタイル → テーマアイコン を ON にする。UI 操作が難しい場合は次のコマンドでも切り替えられる。

```bash
export ANDROID_HOME=/home/spica/Android/Sdk
"$ANDROID_HOME/platform-tools/adb" shell settings put secure theme_customization_overlay_packages '{"android.theme.customization.themed_icon":"1"}'
"$ANDROID_HOME/platform-tools/adb" shell am force-stop com.google.android.apps.nexuslauncher
```

- [ ] **Step 2: テーマアイコン表示を撮る**

```bash
export ANDROID_HOME=/home/spica/Android/Sdk
ADB="$ANDROID_HOME/platform-tools/adb"
"$ADB" shell input keyevent KEYCODE_HOME
"$ADB" shell input swipe 540 1800 540 600
sleep 2
"$ADB" exec-out screencap -p > docs/icon/themed_icon.png
```

- [ ] **Step 3: テーマアイコンを目視で検証する**

`docs/icon/themed_icon.png` で、単色化されたアイコンでも**豆の穴と割れ目が残っている**ことを確認する。豆が消えてのっぺりしたピンになっている場合、前景に不透明な塗りが混入している（設計の前提が崩れている）ので、Task 2 Step 1 の drawable を見直す。

- [ ] **Step 4: 小サイズ表示を撮る**

アプリ情報画面のアイコンは小サイズで表示される。

```bash

"$ADB" exec-out screencap -p > docs/icon/small_size.png
```

パッケージ名が異なる場合は次で確認する。


- [ ] **Step 5: 小サイズ表示を目視で検証する**

`docs/icon/small_size.png` で、豆の割れ目が識別できることを確認する。割れ目が完全に消えている場合は、Task 2 Step 1 の `android:strokeWidth` を 4 から 4.5 に上げて Task 2 Step 5 以降をやり直し、その旨をユーザーに報告する。

- [ ] **Step 6: テーマアイコンを元に戻す**

```bash

"$ANDROID_HOME/platform-tools/adb" shell settings put secure theme_customization_overlay_packages '{}'
```

- [ ] **Step 7: コミット**

## 未検証・要注意事項

- `VectorDrawable` の弧コマンドにおける `x-axis-rotation` の符号（`-45`）は、Android の `PathParser` の実装で確認していない。Task 2 Step 8 の目視検証で傾きが逆だった場合は `45` に変える。
- `-d pixel_7` のデバイスプロファイルが利用可能であることは `avdmanager list device` で確認済みだが、AVD 作成自体は未実行。
- `./gradlew :app:installDebug` には `secrets.properties` の `MAPS_API_KEY` が必要。存在しない場合はユーザーに確認する。
